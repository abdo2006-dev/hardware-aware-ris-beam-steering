## Initial reproducibility findings

- The checked-in uncertainty CSV was generated by `verify_and_sweep.py` outside
  the public repository. That pipeline uses a 2 degree uncertainty grid and a
  1 degree deterministic grid. The zero-noise discrepancy is reproducible from
  that configuration difference.
- The checked-in MATLAB source uses 1 degree grids in both paths. A fresh MATLAB
  R2026b batch run of the original source succeeded: zero noise gives 0 degree
  pointing error and -5.4000021579367 dB target gain. The alleged 400-by-400
  expansion is NOT observed with the original row-vector state table: MATLAB's
  vector-indexing rule followed by the transpose produces a column. Explicit
  reshape/assertions will remove the reliance on that shape rule.
- Original gain is target-grid gain, although labeled peak gain. Original scan
  covers only polar 0..60 and azimuth -60..60 degrees. It misses the mirror beam
  of real binary weights. Original theta is polar angle, not elevation.
- Original figures were separately normalized and cannot display hardware peak
  loss directly. Some historical grid sums were not solid-angle integrals.
- CST construction history includes a continuous copper backplane, omitted from
  the published redrawn side view. Diode lands appear to meet upper/lower arms
  only at corners (zero-area contact in the XY plane). This is a hypothesis to
  test against actual CAD and controlled load diagnostics, not yet a proven
  explanation of the failed reflection contrast.
- MATLAB initially failed under sandboxed launch because the licensed profile
  was not writable. An approved elevated batch launch worked. The original
  function ran in an isolated preservation folder and did not replace old data.
